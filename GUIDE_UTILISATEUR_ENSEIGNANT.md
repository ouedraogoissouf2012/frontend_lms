## Plateforme LMS KLASSCI

# Comment se connecter

1. Ouvrez votre navigateur (Chrome, Firefox, Safari...)
2. Tapez l'adresse : **presentation.klassci.com**
3. Vous arrivez sur la page de connexion

**Sur la page de connexion :**
- Entrez votre **email** dans le premier champ
- Entrez votre **mot de passe** dans le deuxième champ
- Cliquez sur le bouton **"Se connecter"**

**Si vous avez oublié votre mot de passe :**
- Cliquez sur "Mot de passe oublié"
- Entrez votre email
- Vous recevrez un lien pour créer un nouveau mot de passe

---

# Créer une nouvelle leçon

**Pour créer une leçon :**
1. Dans une matière, onglet **Leçons**
2. Cliquez sur **"Nouvelle leçon"**
3. Un formulaire (modal) s'ouvre

**Remplissez le formulaire :**

- **Titre de la leçon** * (obligatoire)
  - Ex: Introduction aux boucles

- **Description**
  - Décrivez brièvement le contenu de cette leçon

- **Prérequis**
  - Connaissances nécessaires avant de suivre cette leçon
  - Ex: Comprendre les variables, les types de données

- **Niveau de difficulté** * (obligatoire)
  - Sélectionnez dans la liste déroulante : Débutant, Intermédiaire, Avancé

- **Objectifs pédagogiques**
  - Que devront savoir faire les étudiants après cette leçon ?
  - Ex: Maîtriser les boucles while et for, Résoudre des problèmes d'itération

- **Durée estimée (minutes)**
  - Temps nécessaire pour compléter toute la leçon
  - Ex: 60

**Pour terminer :**
- Cliquez sur **"Annuler"** pour fermer sans enregistrer
- Cliquez sur **"Créer la leçon"** pour créer votre leçon

**Après avoir cliqué "Créer la leçon" :**
- Vous êtes **automatiquement redirigé** vers la page de gestion des chapitres
- Vous pouvez commencer à ajouter le contenu de votre leçon

---

# Page de gestion des chapitres

Après avoir cliqué **"Créer la leçon"**, vous arrivez automatiquement sur cette page.

**Ce que vous voyez en haut :**
- Lien **"← Retour"** pour revenir à la matière
- **Titre de la leçon** (ex: "cours")
- **Deux badges** :
  - Badge de niveau (ex: **Débutant** en bleu)
  - Badge de statut : **Brouillon** (orange avec icône crayon)
- À droite : bouton **"Prévisualiser"** et bouton vert **"Publier la leçon"**

**Section "Chapitres de la leçon" :**
- Titre : "Chapitres de la leçon"
- Sous-titre : "Organisez votre leçon en chapitres. Chaque chapitre peut avoir un type de contenu différent."
- **Un premier chapitre est déjà ouvert** (Chapitre 1) prêt à être rempli

---

# Remplir un chapitre

**Pour chaque chapitre, vous devez remplir :**

**1. Titre du chapitre**
- Champ texte : "saisissez le titre"

**2. Type de contenu** (liste déroulante)

| Option | Description |
|--------|-------------|
| **Texte / Markdown** | Éditeur de texte riche (par défaut) |
| **Vidéo (YouTube, Vimeo)** | Intégrer une vidéo en ligne |
| **PowerPoint (upload .pptx)** | Télécharger un fichier PowerPoint |
| **Document Word (upload .docx)** | Télécharger un fichier Word |
| **PDF (upload .pdf)** | Télécharger un fichier PDF |
| **Lien externe** | Rediriger vers un site web |
| **Quiz / Testez vos connaissances** | Créer un quiz pour les étudiants |

---

# Contenu selon le type choisi

**Si vous choisissez "Texte / Markdown" :**
- Éditeur de texte riche avec barre d'outils :
  - **Mode étendu** : pour plus d'options
  - **Police** : choix de la police
  - **Formatage** : Gras (B), Italique (I), Souligné (U), Barré (S)
  - **Couleurs** : couleur du texte et surlignage
  - **Alignement** : gauche, centré, droite, justifié
  - **Titres** : H1, H2, H3
  - **Listes** : à puces, numérotées
  - **Tableau** : insérer un tableau
  - **Citation, code**
  - **Ligne horizontale**
  - **Lien** : insérer un lien
  - **Image** : insérer une image
  - **Vidéo** : insérer une vidéo
- Zone de texte : "Rédigez votre contenu ici... (Markdown supporté)"

**Si vous choisissez "Vidéo (YouTube, Vimeo)" :**
- Champ URL : collez le lien de la vidéo (ex: https://www.youtube.com/watch?v=...)
- Option : case à cocher **"Lecture automatique"**

**Si vous choisissez "PowerPoint", "Word" ou "PDF" :**
- Bouton **"Ajouter un media"** pour télécharger votre fichier
- Taille maximale : **30 MB**
- Formats acceptés selon le type :
  - PowerPoint : .pptx
  - Word : .docx
  - PDF : .pdf

**Si vous choisissez "Lien externe" :**
- Champ URL : entrez l'adresse du site (ex: https://...)

**Si vous choisissez "Quiz / Testez vos connaissances" :**
- Éditeur de quiz intégré
- Vous pouvez créer des questions avec plusieurs réponses
- Les étudiants pourront tester leurs connaissances à la fin du chapitre

# Publier une leçon

**Une leçon en brouillon n'est pas visible par les étudiants.**

**Pour publier :**
1. Allez dans la matière concernée
2. Trouvez la leçon (marquée "Brouillon")
3. Cliquez sur le bouton **"Publier"**
4. Confirmez

**Une fois publiée :**
- Les étudiants peuvent voir la leçon
- Le badge devient vert "Publiée"

**Pour dépublier :**
- Cliquez sur **"Dépublier"** sur une leçon publiée
- Elle redevient brouillon

# Créer une version en ligne (QCM)

Les évaluations viennent de KLASSCI. Vous pouvez créer une **version en ligne** avec des QCM pour chaque évaluation.

**Étape 1 - Créer la version en ligne :**
1. Allez dans **"Évaluations"**
2. Trouvez l'évaluation KLASSCI souhaitée
3. Cliquez sur **"Créer version en ligne"**
4. Une fenêtre modale s'ouvre

**Dans la fenêtre modale :**
- Vous voyez les infos de l'évaluation KLASSCI (Titre, Matière, Classe)
- Remplissez :
  - **Type d'évaluation** : QCM uniquement, QCM à choix multiples, ou Mixte (QCM + réponses courtes)
  - **Durée (en minutes)** (obligatoire)
  - **Description / Consignes** : instructions pour les étudiants
- Cliquez sur **"Créer et ajouter des questions"**

**Étape 2 - Ajouter les questions :**
Après la création, vous arrivez sur la page **"Créer les questions QCM"**

**En haut de la page :**
- Bouton **"Retour"**
- Informations de l'évaluation KLASSCI : Évaluation, Matière, Classe, Barème

**Section Configuration :**
- **Durée (minutes)** (obligatoire)
- **Tentatives autorisées** : nombre de fois que l'étudiant peut repasser (1 à 5)
- **Mélanger les questions** (case à cocher)
- **Afficher les résultats immédiatement** (case à cocher)

**Section Questions QCM :**
Cliquez sur **"Ajouter une question"**

**Pour chaque question :**
1. **Énoncé de la question** (obligatoire) : tapez votre question
2. **Type de question** :
   - QCM (Choix unique)
   - QCM (Choix multiples)
   - Vrai/Faux
   - Réponse courte
3. **Points** : nombre de points pour cette question
4. **Options de réponse** (pour QCM/Vrai-Faux) :
   - Tapez chaque option dans les champs
   - Cochez la/les bonne(s) réponse(s) avec le bouton radio/checkbox à gauche
   - Cliquez sur **"Ajouter une option"** pour plus d'options
5. **Réponse(s) acceptée(s)** (pour Réponse courte) : séparez par des virgules

**Pour supprimer une question :**
- Cliquez sur l'icône poubelle en haut à droite de la question

**Pour supprimer une option :**
- Cliquez sur l'icône X à droite de l'option

**Pour enregistrer :**
- Cliquez sur **"Enregistrer et activer"**
- L'évaluation devient disponible pour les étudiants

# Séances et Visioconférences

Les visioconférences utilisent **Jitsi Meet** (solution open source).

## Accéder aux visioconférences

**Depuis l'emploi du temps :**
1. Cliquez sur **"Emploi du Temps"** dans le menu latéral
2. Cliquez sur une séance avec visio programmée
3. Vous arrivez sur la page de détails de la séance

## Page de détails d'une séance (avec visio)

**Ce que vous voyez :**

**En-tête :**
- Bouton **"← Retour"**
- Nom de la matière
- Informations : Date, Horaire, Enseignant, Classe, Salle

**Section "Visioconférence Jitsi" :**
- Statut de la fenêtre temporelle :
  - "La visio ouvrira 15 minutes avant le cours"
  - "Fenêtre visio active" (vert)
  - "Fenêtre visio fermée"
- Si le cours est **EN DIRECT** : badge rouge "COURS EN DIRECT"

**Boutons selon le statut :**
- **"Démarrer le cours"** (bleu) : si vous êtes dans la fenêtre temporelle (15 min avant)
- **"Rejoindre le cours"** (vert) : si le cours est déjà en direct

---

## Démarrer une visioconférence

**Pour démarrer une visio :**
1. Allez dans **"Emploi du Temps"**
2. Cliquez sur votre séance programmée
3. Attendez d'être dans la fenêtre temporelle (15 min avant le cours)
4. Cliquez sur **"Démarrer le cours"** (bouton bleu)
5. Une nouvelle fenêtre Jitsi Meet s'ouvre automatiquement

**Note :** Vous ne pouvez démarrer le cours que si :
- La séance a la visio activée
- Vous êtes dans la fenêtre temporelle (15 min avant → 30 min après l'heure prévue)

---

## Pendant la visioconférence (interface Jitsi)

Une fois dans Jitsi Meet, vous avez accès aux contrôles :
- **Micro** : activer/désactiver votre micro
- **Caméra** : activer/désactiver votre caméra
- **Partage d'écran** : montrer votre écran aux étudiants
- **Chat** : envoyer des messages texte
- **Lever la main** : signaler que vous voulez parler
- **Paramètres** : réglages audio/vidéo

**Note :** Ces contrôles sont ceux de Jitsi Meet, pas de la plateforme LMS.

---

## Terminer la visioconférence

**Pour terminer la séance pour tous les participants :**
1. Retournez sur la page de la séance dans la plateforme LMS
2. Cliquez sur **"Terminer pour tous"** (bouton rouge)
3. Confirmez la fermeture
4. Tous les participants sont déconnectés avec leurs heures de présence enregistrées

---

## Télécharger les présences

**Après une visioconférence :**
1. Sur la page de la séance
2. Cliquez sur **"Télécharger présences (PDF)"** (bouton violet)
3. Un fichier PDF avec la liste des présences est téléchargé

Le PDF contient :
- Liste des étudiants présents
- Heure d'arrivée et de départ de chaque participant
- Durée de présence

---

## Voir les participants

**Pour voir les participants attendus :**
1. Sur la page de la séance
2. Cliquez sur **"Participants (X)"** où X = nombre d'étudiants
3. Une fenêtre modale s'ouvre avec la liste des étudiants de la classe

# En cas de problème

**L'écran est blanc ou ne charge pas :**
- Rafraîchissez la page (touche F5)
- Vérifiez votre connexion internet

**Je ne peux pas télécharger un fichier :**
- Vérifiez que le fichier fait moins de 50 Mo
- Formats acceptés : PDF, Word, PowerPoint, images

**La visio ne se lance pas :**
- Autorisez l'accès au micro/caméra
- Utilisez Chrome ou Firefox
- Vérifiez que la séance a bien commencé

**Une leçon ne s'affiche pas pour les étudiants :**
- Vérifiez qu'elle est bien **publiée** (pas en brouillon)
- Vérifiez que la matière est bien assignée à la classe

**Les résultats d'évaluation ne sont pas visibles :**
- Vérifiez que vous avez cliqué sur **"Publier les résultats"**

**Pour toute autre question :**
- Contactez le coordinateur de votre établissement
- Ou l'administrateur de la plateforme
