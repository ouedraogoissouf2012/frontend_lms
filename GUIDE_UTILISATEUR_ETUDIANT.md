# Guide Utilisateur - ÉTUDIANT
## Plateforme LMS KLASSCI

---

# Comment se connecter

1. Ouvrez votre navigateur (Chrome, Firefox, Safari...)
2. Tapez l'adresse : **presentation.klassci.com**
3. Vous arrivez sur la page de connexion

**Sur la page de connexion :**
- Entrez votre **email** dans le premier champ
- Entrez votre **mot de passe** dans le deuxième champ
- Cliquez sur le bouton **"Se connecter"**

**Si vous avez oublié votre mot de passe :**
- Cliquez sur "Mot de passe oublié"
- Entrez votre email
- Vous recevrez un lien pour créer un nouveau mot de passe

---

# Page d'Accueil (Dashboard)

Après la connexion, vous arrivez sur votre **Tableau de bord**.

**Ce que vous voyez :**
- En haut : votre nom et une icône de notification
- Au centre : vos statistiques (nombre de cours, notes, séances à venir)
- En bas : les cours récents et les prochaines activités

**Sur téléphone :**
- En bas de l'écran, vous avez 5 boutons :
  - 🏠 Accueil
  - 📚 Cours
  - ✏️ Évaluations
  - 📅 Emploi
  - ⚙️ Paramètres

---

# Consulter mes cours

**Pour voir la liste de vos cours :**

1. Cliquez sur **"Mes Cours"** dans le menu (ou l'icône 📚 sur téléphone)
2. Vous voyez la liste de tous vos cours sous forme de cartes

**Ce que vous voyez pour chaque cours (une carte) :**
- Le nom de la matière (ex: Marketing digital, Algorithme, Anglais)
- Le coefficient (ex: Coeff: 1)
- 3 chiffres en dessous :
  - **Leçons** : nombre de leçons disponibles
  - **Séances** : nombre de séances programmées
  - **Éval.** : nombre d'évaluations
- Un bouton bleu **"Voir détails →"**

**Pour ouvrir un cours :**

1. Cliquez sur **"Voir détails →"** sur la carte du cours
2. Vous arrivez sur la page de détails de la matière

**Ce que vous voyez sur la page de détails :**

En haut :
- Le fil d'ariane (ex: Mes Cours > Marketing digital)
- Le nom de la matière en grand (ex: Marketing digital)
- Les informations : Code, Coefficient, Heures

Au milieu :
- Des chiffres : nombre de Leçons, Séances, Évaluations
- Des onglets pour naviguer : **Leçons**, **Séances**, **Évaluations**, **Classes**

**Onglet Leçons :**
- Vous pouvez choisir l'affichage : **Grille** ou **Liste**
- Chaque leçon affiche :
  - Un badge (ex: COURS, TP, TD)
  - Le titre de la leçon
  - Une courte description
  - Votre progression (ex: Terminé 100%)
  - La date
  - Un bouton **"Consulter"**

**Pour consulter une leçon :**

1. Cliquez sur **"Consulter"** sur la leçon qui vous intéresse
2. Vous voyez le contenu de la leçon avec ses chapitres

**Ce que vous voyez dans une leçon :**
- Le titre et la description
- La liste des chapitres
- Pour chaque chapitre : du texte, des vidéos, des documents PDF

**Quiz "Testez vos connaissances" :**

À la fin de certains chapitres, il y a un petit quiz :
1. Cliquez sur **"Testez vos connaissances"**
2. Répondez aux questions
3. Cliquez sur **"Valider"**
4. Vous voyez votre score

# Voir mon emploi du temps

**Pour voir vos séances programmées :**

1. Cliquez sur **"Emploi du Temps"** dans le menu (ou l'icône 📅 sur téléphone)
2. Vous voyez un calendrier avec vos séances

**Ce que vous voyez :**
- Les jours de la semaine
- Les séances avec :
  - L'heure de début et de fin
  - Le nom de la matière
  - Le nom de l'enseignant
  - 📹 Une icône caméra si c'est une visioconférence

**Pour naviguer dans le calendrier :**
- Cliquez sur **◀** pour voir la semaine précédente
- Cliquez sur **▶** pour voir la semaine suivante

**Pour voir les détails d'une séance :**
1. Cliquez sur la séance
2. Vous voyez :
   - La matière
   - L'enseignant
   - L'heure exacte
   - Le type (présentiel ou en ligne)

---

# Participer à une visioconférence

**Quand une séance en ligne est programmée :**

1. Allez dans **"Emploi du Temps"**
2. Trouvez la séance avec l'icône 📹
3. Cliquez sur la séance
4. Quand c'est l'heure, un bouton **"Rejoindre la visio"** apparaît
5. Cliquez sur **"Rejoindre la visio"**

**Une nouvelle fenêtre s'ouvre avec la salle de classe virtuelle.**

**Ce que vous pouvez faire :**
- 🎤 **Micro** : Cliquez pour activer/désactiver votre micro
- 📹 **Caméra** : Cliquez pour activer/désactiver votre caméra
- 💬 **Chat** : Écrivez des messages aux autres participants
- 👋 **Lever la main** : Pour poser une question

**Pour quitter la visio :**
- Cliquez sur le bouton rouge **"Quitter"**
- Vous revenez sur la plateforme

---

# Passer une évaluation

**Pour voir vos évaluations :**

1. Cliquez sur **"Évaluations"** dans le menu (ou l'icône ✏️ sur téléphone)
2. Vous voyez la liste des évaluations

**Ce que vous voyez :**
- Le titre de l'évaluation
- La matière
- Le statut :
  - 🟢 **Disponible** : Vous pouvez la passer
  - 🟡 **En cours** : Vous avez commencé mais pas terminé
  - ✅ **Terminée** : Vous l'avez déjà passée

**Pour passer une évaluation :**

1. Cliquez sur une évaluation **Disponible**
2. Vous voyez les informations :
   - Durée (ex: 30 minutes)
   - Nombre de questions
   - Instructions de l'enseignant
3. Cliquez sur **"Commencer l'évaluation"**

**Pendant l'évaluation :**
- Vous voyez une question à la fois
- En haut : le temps restant ⏱️
- Choisissez votre réponse en cliquant dessus
- Cliquez sur **"Suivant"** pour passer à la question suivante
- Cliquez sur **"Précédent"** pour revenir en arrière

**⚠️ Important :**
- Ne fermez pas la fenêtre pendant l'évaluation
- Le temps continue même si vous quittez

**Pour terminer :**
1. Après la dernière question, cliquez sur **"Terminer"**
2. Un message vous demande de confirmer
3. Cliquez sur **"Confirmer"**
4. Vous voyez votre résultat (si l'enseignant l'a autorisé)

---

# Voir mes notes

**Pour consulter vos résultats :**

1. Cliquez sur **"Mes Notes"** dans le menu
2. Vous voyez vos résultats

**Ce que vous voyez :**
- Votre moyenne générale
- La liste de vos évaluations notées avec :
  - Le titre
  - La matière
  - Votre note (ex: 15/20)
  - La date

**Pour voir le détail d'une note :**
1. Cliquez sur l'évaluation
2. Vous voyez :
   - Chaque question
   - Votre réponse
   - La bonne réponse (en vert)
   - Les commentaires de l'enseignant (si disponibles)

---

# Utiliser le Forum

**Le forum permet de discuter avec vos camarades et enseignants.**

**Pour accéder au forum :**
1. Cliquez sur **"Forum"** dans le menu

**Ce que vous voyez :**
- Liste des discussions (sujets)
- Pour chaque sujet :
  - Le titre
  - L'auteur
  - Le nombre de réponses
  - La date du dernier message

**Pour lire une discussion :**
1. Cliquez sur le titre du sujet
2. Vous voyez tous les messages

**Pour répondre :**
1. Descendez en bas de la discussion
2. Tapez votre message dans la zone de texte
3. Cliquez sur **"Publier"**

**Pour créer un nouveau sujet :**
1. Cliquez sur **"Nouveau sujet"**
2. Entrez un titre
3. Écrivez votre message
4. Cliquez sur **"Publier"**

---

# Modifier mes paramètres

**Pour accéder à vos paramètres :**

1. Cliquez sur **"Paramètres"** dans le menu (ou l'icône ⚙️ sur téléphone)

**Ce que vous pouvez faire :**

**Changer le thème (couleurs) :**
- Cliquez sur **"Thème clair"** ou **"Thème sombre"**
- L'écran change immédiatement de couleur

**Voir vos informations :**
- Votre nom
- Votre email
- Votre classe

**Se déconnecter :**
1. Descendez en bas de la page
2. Cliquez sur **"Déconnexion"**
3. Vous revenez à la page de connexion

# En cas de problème

**L'écran est blanc ou ne charge pas :**
- Rafraîchissez la page (touche F5 ou bouton ↻)
- Vérifiez votre connexion internet

**J'ai oublié mon mot de passe :**
- Sur la page de connexion, cliquez "Mot de passe oublié"
- Contactez votre établissement si ça ne fonctionne pas

**Une vidéo ne se lance pas :**
- Vérifiez votre connexion internet
- Essayez un autre navigateur (Chrome recommandé)

**Je n'arrive pas à rejoindre la visio :**
- Vérifiez que la séance a bien commencé
- Autorisez l'accès à votre micro/caméra quand demandé

**Pour toute autre question :**
- Contactez votre enseignant
- Ou le secrétariat de votre établissement
